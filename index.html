Implementation notes

Key fixes in this version

  • The blur now works because blur() and scale() are handled separately.
  • The Wikidata query is filtered to sovereign states to avoid local leaders like mayors.
  • Each country includes map coordinates so guesses can show a geographic proximity emoji bar.

Emoji distance bar

The distance indicator uses country coordinates and a haversine calculation. The closer the guess, the more green squares appear. The exact country shows 🟩🟩🟩🟩🟩.

This is still best treated as a polished front-end prototype. For a real launch, move the daily answer selection to a backend or serverless function.
